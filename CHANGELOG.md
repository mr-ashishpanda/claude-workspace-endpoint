# Changelog

All notable changes to this project are documented in this file. Format loosely follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

- Open-source readiness: LICENSE, SECURITY.md, CONTRIBUTING.md, CODE_OF_CONDUCT.md, issue/PR
  templates, badges, and documentation cleanup for public release.

## [0.1.0]

- Initial local-first Slack-Claude bridge: Socket Mode Slack app, per-channel/thread session
  scopes, mention/auto trigger modes, per-mapping Claude identity, persistent sessions, `@claude
status` command, CLI (`init`, `map add|list|edit|remove`, `run|stop|logs`), image upload support,
  live channel validation, cross-platform per-user config/state directories, and log rotation.
